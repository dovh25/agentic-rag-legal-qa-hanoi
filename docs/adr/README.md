# Architecture Decision Records (ADR)

This directory documents important architectural and design decisions for the Agentic RAG Legal QA project.

## Structure of an ADR
1. **Title**: ADR number and concise decision title.
2. **Status**: Proposed / Accepted / Superseded.
3. **Context**: Problem statement and drivers.
4. **Decision**: Solution selected.
5. **Consequences**: Trade-offs, benefits, and drawbacks.

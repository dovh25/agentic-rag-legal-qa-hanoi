# Agent Workflow Development Skill

This skill provides developer guidance for modifying, extending, and verifying the LangGraph state graph and FastAPI endpoints for the Hanoi Legal QA system.

---

## 1. Graph Architecture & Flow

```text
       [START]
          │
      ▼───▼────▼
      │ router │
      └───┬────┘
   ┌──────┼────────────────┐
   │      │ (multi_hop)    │ (clarification)
   │      ▼                ▼
   │  ┌─────────┐   ┌───────────────┐
   │  │ planner │   │ clarification │──► [END]
   │  └────┬────┘   └───────────────┘
   │       │
   ▼       ▼
┌──────────────┐

└──────┬───────┘
       │
       ▼

└──────┬───────┘
       │
       ▼
┌──────────────┐
│    verify    │ (citation & entailment check)
└──────┬───────┘
       │
       ▼
    [END]
```

## 2. Agent State Specification

The state is defined in `src/agent/state.py:AgentState`:

```python
class AgentState(TypedDict, total=False):
    query: str
    as_of_date: Optional[str]
    district: Optional[str]
    route: str  # "single_hop" | "multi_hop" | "clarification"
    sub_queries: List[str]  # Generated by planner for multi-hop
    retrieved_documents: List[Dict]  # Chunks with metadata & scores
    answer: str  # Grounded synthesized response
    citations: List[Dict]  # Verified citations
    status: str  # "answered" | "insufficient_evidence" | "clarification_needed"
    reasoning_steps: List[str]  # Audit trail of agent decisions
    error: Optional[str]
```

## 3. Modifying & Extending Nodes

All node implementations reside in `src/agent/nodes.py`:
- `router_node(state)`: Analyzes query complexity, extracts district/temporal parameters, determines routing.
- `planner_node(state)`: Decomposes complex multi-hop queries into atomic sub-queries.
- `retrieval_node(state)`: Executes hybrid retrieval via `src/agent/tools.py`.
- `synthesize_node(state)`: Builds strict evidence-based answer with draft citations.
- `verify_node(state)`: Checks citation provenance, verifies text quote matches, and abstains if evidence is unsupported.
- `clarification_node(state)`: Formulates targeted questions to obtain missing user parameters.

Graph assembly and conditional routing reside in `src/agent/graph.py`.

## 4. Testing & Verification Runbook

### Step 1: Unit & Flow Tests
Run the dedicated agent flow tests to verify routing and graph state transitions:
```bash
pytest tests/eval/test_agent_flow.py -v
```

### Step 2: API Integration Tests
Verify FastAPI endpoints with pytest:
```bash
pytest tests/integration/test_api.py -v
```

### Step 3: Local Dev Server & Interactive Swagger
Start the dev server:
```bash
make dev
```
Open Swagger UI at `http://localhost:8000/docs` to test `POST /api/v1/query`.

Example request payload:
```json
{
  "query": "Quy định về bồi thường đất nông nghiệp khi nhà nước thu hồi tại Hà Nội?",
  "as_of_date": "2026-10-04",
  "top_k": 5
}
```

### Step 4: Code Quality Check
Before committing any changes:
```bash
make lint
make format
```

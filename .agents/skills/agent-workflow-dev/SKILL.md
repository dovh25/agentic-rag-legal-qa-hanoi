# Agent Workflow Development Skill

This skill provides developer guidance for modifying, extending, and verifying the LangGraph state graph and FastAPI endpoints for the Hanoi Legal QA system, fully synchronized with [docs/PRD.md](../../docs/PRD.md), [docs/Brief.md](../../docs/Brief.md), and [docs/Wireframe_UI_Flow.md](../../docs/Wireframe_UI_Flow.md).

## 1. Graph Architecture & Flow

```text
               [START]
                  │
              ▼───▼────▼
              │ router │ (Intent classification, District, as_of_date)
              └───┬────┘
     ┌────────────┼────────────────┐
     │            │ (multi_hop)    │ (clarification)
     │            ▼                ▼
     │        ┌─────────┐   ┌───────────────┐
     │        │ planner │   │ clarification │──► [END]
     │        └────┬────┘   └───────────────┘
     │             │
     ▼             ▼
  ┌───────────────────┐
  │     retrieval     │ (Hybrid: dense BGE-M3 1024-dim + BM25, Payload filter)
  └─────────┬─────────┘
            │
            ▼
  ┌───────────────────┐
  │      grader       │ (Relevance checking & noise reduction)
  └─────────┬─────────┘
     ┌──────┴────────────────┐
     │ (relevance >= 1)      │ (0 chunks relevant)
     ▼                       ▼
┌──────────────┐     ┌────────────────────────────────────┐
│  synthesize  │     │ status = "insufficient_evidence"   │──► [END]
└──────┬───────┘     └────────────────────────────────────┘
       │
       ▼
┌──────────────┐
│    verify    │ (Citation & quote verification, URL check)
└──────┬───────┘
       │
       ▼
    [END] (status: "answered")
```

## 2. Agent State Specification

The state is defined in `src/agent/state.py:AgentState` matching PRD Section 6 & 10:

```python
class AgentState(TypedDict, total=False):
    query: str
    as_of_date: str | None  # Input date or default today (YYYY-MM-DD)
    as_of_date_applied: str | None  # Effective date actually applied
    district: str | None  # Extracted Hanoi district/town
    route: str  # "single_hop" | "multi_hop" | "clarification"
    sub_queries: list[str]  # Generated by planner for multi-hop
    retrieved_documents: list[dict]  # Chunks with metadata & scores
    answer: str | None  # Grounded synthesized response
    citations: list[dict]  # Verified legal citations
    status: str  # "answered" | "insufficient_evidence" | "clarification_needed"
    clarification_question: str | None  # Prompt question for user when clarification needed
    reasoning_steps: list[str]  # Audit trail of agent decisions
    processing_time_ms: float | None  # Execution latency
    error: str | None
```

## 3. Modifying & Extending Nodes

All node implementations reside in `src/agent/nodes.py`:
- `router_node(state)`: Analyzes query complexity, extracts district (30 Hanoi districts) and `as_of_date`, routes to `single_hop`, `multi_hop`, or `clarification`.
- `planner_node(state)`: Decomposes complex comparative queries into atomic sub-queries (e.g., Central Law vs. Hanoi Decree).
- `retrieval_node(state)`: Executes hybrid retrieval via Qdrant Client (Dense BGE-M3 + BM25 + Payload Filter: `legal_status == 'active'` and `administrative_area` contains `Hà Nội`).
- `synthesize_node(state)`: Builds strict evidence-based answer with structured citations (`doc_id`, `document_title`, `document_number`, `article_ref`, `clause`, `snippet`, `source_url`, `effective_date`).
- `verify_node(state)`: Checks citation provenance, verifies text quote matches, and abstains if evidence is unsupported.
- `clarification_node(state)`: Formulates targeted questions when query lacks required legal parameters.

Graph assembly and conditional routing reside in `src/agent/graph.py`.

## 4. API Endpoints Specification

Conforming to **PRD Section 10**:

### `POST /api/v1/query`
Main query endpoint.
Request:
```json
{
  "query": "Hạn mức giao đất ở tại quận Cầu Giấy theo quy định mới nhất?",
  "as_of_date": "2026-10-04",
  "district": "Cầu Giấy",
  "max_results": 5
}
```

Response:
```json
{
  "query": "Hạn mức giao đất ở tại quận Cầu Giấy...",
  "status": "answered",
  "answer": "Theo Quyết định 61/2024/QĐ-UBND...",
  "citations": [
    {
      "doc_id": "61-2024-QD-UBND",
      "document_title": "Quyết định 61/2024/QĐ-UBND của UBND TP. Hà Nội",
      "document_number": "61/2024/QĐ-UBND",
      "article_ref": "Điều 14",
      "clause": "Khoản 1",
      "snippet": "...",
      "source_url": "https://congbao.hanoi.gov.vn/..."
    }
  ],
  "reasoning_steps": ["Router: single_hop", "Retrieve: 5 chunks", "Grade: 4/5 relevant"],
  "route": "single_hop",
  "processing_time_ms": 3250.5
}
```

### `GET /api/v1/health`
System health check returning Qdrant, LLM status, and indexed corpus size.

### `POST /api/v1/feedback`
User feedback collection (`query_id`, `rating`, `comment`).

## 5. Testing & Verification Runbook

### Step 1: Unit & Flow Tests
```bash
pytest tests/eval/test_agent_flow.py -v
pytest tests/unit/test_schemas.py -v
```

### Step 2: API Integration Tests
```bash
pytest tests/integration/test_api.py -v
```

### Step 3: Run Dev Server & Interactive Swagger
```bash
make dev
```
Open Swagger UI at `http://localhost:8000/docs`.

### Step 4: Code Quality Check
```bash
make lint
make format
```
